# 片刻 Playroom

片刻 Playroom 提供 132 款在线小游戏和共享纪录榜。大厅、游戏和榜单的首屏 HTML 由服务端渲染，浏览器接管操作、存档和站内导航。

## 本地运行

需要 Node.js 22.12.0 或以上版本。CI 使用 `.node-version` 锁定的版本，Wrangler 由项目的依赖锁安装。

```sh
npm ci
npm run dev
```

打开终端显示的地址（默认为 `http://127.0.0.1:5173`）。端口占用时可以运行 `npm run dev -- --port 5174`。

本地榜单由 Node.js 管理，数据目录不会打包进 `dist/` 或通过静态路由提供。可用 `node scripts/serve.mjs --data-dir /absolute/private/path` 指定私有目录；不要让两个服务实例同时使用同一目录。退出服务会释放写锁；异常崩溃后，先确认原进程已经停止，备份数据，再由维护者处理残留的 `records.lock`。备份账号 / 排名时应停止服务后复制私有目录，切勿发布该目录。

```sh
npm test         # 全部游戏的规则、状态与计分验证
npm run build    # 检查 JavaScript 语法并生成 dist/
npm run preview  # 预览 dist/ 中的构建结果
```

## 线上地址与搜索收录

正式域名为 `https://games.uutom.com`。`/` 是游戏大厅，`/games/:id` 是游戏，`/records` 和 `/records/:id` 是榜单。旧的 `#/…` 游戏书签仍可打开。`/robots.txt` 声明站点地图地址。`/sitemap.xml`、标题、页面描述和 canonical 由同一路由目录生成。

线上入口为 Cloudflare Worker `playroom-games`，账号和成绩由 SQLite Durable Object `GameRecords` 持久保存。Cloudflare 依据 `wrangler.json` 绑定自定义域名。`npm run build` 生成浏览器资源、许可证和本地预览模板。部署时仅上传静态资源清单内的文件；模板由 Worker 用于服务端渲染。

GA4 使用 `dengruo` 账号内的「片刻 Playroom」媒体资源，衡量 ID 为 `G-VPY9P2ZPV3`。只在正式域名发送页面浏览，站内导航和前进后退按规范 URL 统计。请保持此数据流的增强型衡量关闭，避免重复统计。Search Console 使用 `https://games.uutom.com/` 网址前缀资源。

## 持续集成与部署

GitHub Actions 在拉取请求和推送 `main` 时运行 `npm ci`、`npm test` 和 `npm run build`。验证通过后，只有 `ruodeng/playroom-games` 的 `main` 推送可进入 `production` 环境依次部署。待部署提交仍需位于 `main` 最新位置，Cloudflare 版本标记为提交哈希的前 12 位。

维护者在 GitHub 的 `production` 环境中添加此项目专用的 `CLOUDFLARE_API_TOKEN`，并将环境的部署分支限制为 `main`。令牌权限限定到现有 Worker 所在的 Cloudflare 账号及 `uutom.com` 区域。拉取请求检查无需发布凭据。已授权的本地维护可用 `npx --no-install wrangler deploy` 执行同一部署入口。回滚应选择现有 Worker 的上一稳定版本，并保留 `GameRecords` 命名空间及数据。[Cloudflare CI 凭据指南](https://developers.cloudflare.com/workers/ci-cd/external-cicd/github-actions/)

## 已支持

- 片刻纪录榜 `/records` 为支持提交成绩的游戏提供按难度或关卡区分的榜单。计分游戏按分数降序，谜题按通关步数、尝试次数或实际游玩用时升序；每位玩家每榜只保留最佳成绩，同分按先取得者优先。对弈类及大富翁暂不参与排名。
- 开始新局时取得服务器票据，结束后自动上传；进入前 10 时提示填写公开昵称。游客无需注册即可参加；可用账号、密码和昵称注册，登录后跨浏览器保留身份。注册 / 登录会合并当前游客的最佳纪录；退出后不会继续使用账号身份提交。
- 服务器持久化账号与成绩，默认私有目录 `.data/records/`。密码使用带随机盐的 scrypt 派生，不保存明文；Cookie 会话、同源检查、请求限流及一次性成绩票据保护基本流程。榜单为休闲交流用途，采用客户端结果及基础异常校验，尚未实施服务端完整对局回放验证。
- 账号目前使用用户名和密码，不包含邮箱验证、密码找回与管理员审核。当前浏览器原有个人最高分继续保留，旧分数不会补录到共享榜单。

- 小游戏大厅支持按名称或玩法搜索，并结合全部、动动脑、练手速和来对弈分类筛选；手机导航可左右滚动。游戏面板在首次进入时创建。
- 导航时保留五子棋棋局；其他游戏离开页面或窗口失焦时自动暂停，返回后手动继续。
- 15×15 自由五子棋：黑棋先行、交替落子，五颗及以上同色棋子连线获胜，无禁手，满盘无胜者为和棋。
- 人机对战：轻松、切磋、挑战三档难度，可选执黑或执白。电脑优先完成五连或阻挡直接威胁；挑战档进一步评估对方应手。AI 在 Web Worker 中计算，不能使用 Worker 时自动在页面内计算。
- 悔棋：回到玩家上次落子前，取消尚未完成的电脑落子。
- 获胜连线、最近一手标记、坐标、落子记录、可选手数、可选音效。
- 浏览器本地存档，刷新或重新打开后继续；不支持存储时明确提示。
- 适配桌面和手机，支持方向键、Home/End、Enter/空格落子以及减少动态效果设置。

设置面板选择的难度和棋色会在点击“开始新对局”后应用。进行中的对局重新开始前需要确认。旧版双人存档会保留棋局和执棋颜色，恢复后由电脑接手对方。

贪吃蛇位于 `/games/snake`，采用 20×20 场地，支持方向键、WASD 和手机方向按钮。每吃一个食物加 10 分并增长一格，撞墙或碰到自己的身体结束，填满场地通关。支持三档速度、暂停、继续和重新开始；离开游戏、失去窗口焦点、切换标签或查看规则时自动暂停，回来后需手动继续。最高分保存在当前浏览器，刷新会重置本局。大厅地址为 `/`，五子棋地址为 `/games/gomoku`。

俄罗斯方块位于 `/games/tetris`，采用 10×20 场地，七种形状按组随机出现。支持左右移动、顺逆时针旋转、加速下落和直接落下；显示落点和接下来三个方块，手机提供操作按钮。一次消除 1 / 2 / 3 / 4 行获得 100 / 300 / 500 / 800 基础分，再乘当前等级；每消除 10 行升一级并加快落速。方向键或 A / D 移动，↑ / W / X 顺时针旋转、Z 逆时针旋转、↓ / S 加速、空格直落，P / Esc 暂停。离开游戏、切换标签、窗口失焦或查看规则时自动暂停。最高分保存在当前浏览器，刷新会重置本局。

## 迷你大富翁

迷你大富翁位于 `/games/monopoly`：你与两位电脑在 24 个地点组成的曲折小镇地图经营，初始现金 1,200，经过起点 +200。20 轮快速局结束按总资产排名（同额并列），仅剩一人时提前结束。支持买地、收租、独立升级最多 3 栋房屋、半价卖房、抵押与赎回；现金不足时可以变现偿债，全部可变现资产不足才能破产。破产后地产回归市场，剩余可变现资产支付债权人；玩家破产后可观看电脑结算。车站、公园、机会事件和城市税带来不同效果，完整规则见游戏内说明。

地图横跨老街、森林、山丘、河岸与海湾，07、17 号地点提供主路 / 近路选择。经过路口且还有剩余步数时进入选路状态；每条连接消耗 1 步，仅最终落点触发事件。电脑会比较候选路线的落点费用，选择更合适的道路。支持地图拖动、缩放、全图与角色定位，地图聚焦后也可用方向键滚动。地点缩略图、手册插画和大厅封面均使用生成图片；图片只用于表现地形，经济规则以手册为准。

地图和 7 类地形插画使用 OpenAI 图像生成工具生成，保存在 `assets/monopoly/`。地点 ID 保持不变，旧版棋盘存档可以继续使用，新版选路中途的存档也可恢复。

大富翁每次操作后自动保存完整局面，刷新后停留在暂停状态，点击继续恢复；打开规则、离开页面或窗口失焦会暂停电脑。无存储权限或存档损坏时明确提示。此存档仅在当前浏览器有效，不支持多个标签同时编辑同一局。P / Esc 暂停，在非按钮区域按空格掷骰；所有操作也可通过按钮完成。
